
# Визуализатор зависимостей пакетов

Практическая работа № 2 по дисциплине «Конфигурационное управление». Вариант 8.

## О проекте

Разрабатывается консольная программа на Python для анализа зависимостей пакетов Alpine Linux (apk).

Работа разделена на пять этапов. На первом этапе реализованы чтение настроек из YAML, проверка параметров и вывод значений в формате «ключ: значение».

Получение зависимостей и построение графа будут добавлены на следующих этапах.

## Структура проекта

```text
config_managment_2/
├── src/
```

Папка `test_data` предназначена для тестового репозитория, который будет использоваться на следующих этапах.

## Настройки

Параметры программы задаются в файле `config/config.yaml`:

```yaml
package: curl
repository: https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64/
test_mode: false
ascii_tree: true
```

Описание параметров:

| Параметр | Назначение |
| --- | --- |
| `package` | Название анализируемого пакета |
| `repository` | URL репозитория или путь к тестовому файлу |
| `test_mode` | Включение тестового режима |
| `ascii_tree` | Включение отображения зависимостей в виде ASCII-дерева |

При `test_mode: false` используется URL настоящего репозитория Alpine Linux.

При `test_mode: true` необходимо указать путь к существующему локальному файлу.

На первом этапе параметры считываются и проверяются. Получение зависимостей и построение ASCII-дерева пока не выполняются.

## Установка и запуск

Для работы необходим Python 3 и библиотека PyYAML. Дополнительная компиляция не требуется.

Все команды выполняются из корневой папки проекта.

Создание виртуального окружения:

```powershell
python -m venv .venv
```

Установка зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запуск программы:

```powershell
.\run.bat
```

Также программу можно запустить напрямую:

```powershell
.\.venv\Scripts\python.exe src\main.py
```

Для использования другого файла конфигурации можно передать его путь:

```powershell
.\.venv\Scripts\python.exe src\main.py config\config.yaml
```

При правильной конфигурации программа выводит:

```text
package: curl
repository: https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64/
test_mode: False
ascii_tree: True
```

## Проверка конфигурации

Реализована проверка всех обязательных параметров.

Программа обнаруживает следующие ошибки:

- Отсутствие обязательного параметра.
- Пустое значение параметра.
- Неправильный тип данных.
- Некорректный формат YAML.
- Отсутствие файла конфигурации.
- Неверный формат URL репозитория.
- Отсутствие тестового файла.
- Несоответствие источника данных выбранному режиму.

Для параметров `package` и `repository` требуется непустая строка.

Параметры `test_mode` и `ascii_tree` должны содержать логические значения `true` или `false`.

В обычном режиме проверяется формат URL. В тестовом режиме проверяется наличие локального файла.

На первом этапе доступность удалённого репозитория через интернет не проверяется.

При обнаружении ошибки программа выводит сообщение и завершается с кодом `1`.

Пример:

```text
Ошибка конфигурации: 'test_mode' должен быть true или false
```

## Основные функции

В файле `src/main.py` реализованы следующие функции:

| Функция | Назначение |
| --- | --- |
| `load_config()` | Чтение конфигурационного YAML-файла |
| `require_text()` | Проверка строковых параметров |
| `require_bool()` | Проверка логических параметров |
| `validate_source()` | Проверка URL или пути к тестовому файлу |
| `validate_config()` | Проверка всех настроек |
| `main()` | Запуск программы и вывод результатов |

Для чтения YAML используется `yaml.safe_load()` из библиотеки PyYAML.

Ошибки чтения и проверки обрабатываются с помощью `try` и `except`.

## Тестирование

Автоматические тесты расположены в файле `tests/test_main.py`.

Для тестирования используется стандартная библиотека Python `unittest`.

Проверяются:

- Правильная конфигурация.
- Отсутствующие и пустые значения.
- Неверные типы данных.
- Ошибки формата YAML.
- Некорректные адреса репозиториев.
- Работа с существующими и отсутствующими тестовыми файлами.

Всего подготовлено 15 автоматических тестов.

Запуск:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

При успешном выполнении всех проверок выводится:

```text
Ran 15 tests in ...

OK
```
